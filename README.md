# HR Analytics Dashboard | Power BI

## Project Overview
An interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee attrition, workforce demographics, department-wise trends, salary slabs, and overtime patterns.

## Objectives
- Analyze employee attrition trends.
- Compare attrition across departments and job roles.
- Understand attrition by salary slab and overtime status.
- Present key HR metrics through interactive visualizations.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Dashboard Insights
- Attrition rate by overtime status.
- Department-wise and job-role-wise attrition analysis.
- Salary slab and employee demographic analysis.
- Interactive KPI cards and charts for HR decision-making.
